# 🎮 Мониторинг и список серверов Roblox

Сайт-хаб игровых серверов Roblox нашего сообщества с поиском, фильтрами режимов, живым счетчиком игроков и кнопками быстрого подключения.

---

## 🌐 Как опубликовать сайт в интернет БЕСПЛАТНО (за 1-2 минуты)

Чтобы любой человек мог зайти на ваш сайт по ссылке (например, `https://my-roblox-servers.netlify.app`), загрузите файлы проекта на бесплатный хостинг:

### Вариант 1. Netlify Drop (Самый простой — без регистрации и терминала)
1. Откройте в браузере сайт: **[app.netlify.com/drop](https://app.netlify.com/drop)**
2. Откройте проводник с папкой `C:\111`.
3. Просто **перетащите папку `111`** (или все файлы внутри) мышью в окно браузера в зону загрузки.
4. Через 5 секунд Netlify выдаст вам готовую публичную ссылку с бесплатным HTTPS-сертификатом!

---

### Вариант 2. GitHub Pages (Идеально для постоянного сайта)
1. Зарегистрируйтесь на **[github.com](https://github.com)**.
2. Создайте новый репозиторий (например, `roblox-servers`).
3. Загрузите файлы: `index.html`, `style.css`, `script.js`, `robots.txt`, `sitemap.xml`.
4. Перейдите в **Settings** $\rightarrow$ **Pages** $\rightarrow$ в разделе **Branch** выберите `main` и нажмите **Save**.
5. Ваш сайт будет доступен по адресу: `https://ваш-логин.github.io/roblox-servers/`.

---

### Вариант 3. Vercel
1. Перейдите на **[vercel.com](https://vercel.com)**.
2. Войдите через GitHub и импортируйте проект в один клик.

## 🔍 Как сделать, чтобы сайт находился в поиске Google и Яндекс?

1. **Опубликуйте сайт** по одной из инструкций выше (у вас появится ссылка в интернете).
2. **SEO-теги уже настроены:** в `index.html` прописаны ключевые слова, описания и заголовки для роботов-поисковиков.
3. **Добавление в поисковики:**
   - Для **Яндекса**: зайдите в [Яндекс.Вебмастер](https://webmaster.yandex.ru), нажмите «Добавить сайт» и вставьте ссылку на ваш сайт.
   - Для **Google**: перейдите в [Google Search Console](https://search.google.com/search-console) и подтвердите адрес сайта.
4. **Discord-превью:** При отправке ссылки в Discord, Telegram или ВКонтакте сайт автоматически покажет красивую карточку с логотипом, описанием и заголовком.

---

## 🛠 Как изменить список своих серверов?

Откройте файл [`script.js`](script.js) — в самом верху находится массив `serversData`. Вы можете вписать туда:
- Название вашего сервера (`title`)
- Ссылку на ваш плейс или VIP-сервер (`link`)
- Категорию (`roleplay`, `pvp`, `survival`, `minigames`)
- Описание (`desc`)
